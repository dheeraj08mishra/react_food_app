## 📖 About the Project  
React Food App is a modern food ordering application that allows users to browse different cuisines, add items to their cart, and place orders seamlessly. It is built using the latest web technologies to ensure a smooth and responsive user experience.

## ✨ Features  

### 🏆 User Experience  
✅ **UI** – Clean and modern user interface with intuitive navigation.  

### 🔍 Search & Filtering  
✅ **Real-time Search** – Users can quickly find restaurants using an instant search feature, providing relevant results as they type.  
✅ **Restaurant Filters** – Users can apply filters to sort and find restaurants based on criteria such as cuisine, ratings, and price range.  

### 🌍 Location-based Features  
✅ **Location Selection** – Users can manually set their location, and the app dynamically fetches restaurants available in that area.  

### 🛒 Ordering & Cart  
✅ **Dynamic Menu** – Fetches food items dynamically and displays them in a categorized manner.  
✅ **Add to Cart** – Users can add and remove items from their cart.  
✅ **Cart Management** – The shopping cart is tied to a specific restaurant, ensuring that users can only order from one restaurant at a time for a seamless checkout experience.  

### 🚀 Performance Optimization  
✅ **Fast Performance** – Optimized for speed with smooth animations and efficient data fetching.  
✅ **Lazy Loading** – Implements lazy loading to load resources only when needed, improving performance and reducing initial load time.

## 🛠 Tech Stack  

### **Frontend**  
- ⚛️ **React.js** – For building the UI components  
- 🚀 **React Router** – For navigation between different pages  
- 💨 **Tailwind CSS** – For styling and responsiveness  
- 🌐 **Redux Toolkit** – For state management  
- 🍽 **API Integration** – Fetching food items dynamically  

### **Backend & Deployment**  
- 🌍 **Vercel** – For fast and efficient hosting
